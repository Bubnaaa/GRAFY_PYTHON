# Program na zanalyzování grafu
### Program analyzuje
- Počet bodů a hrany grafu
- Zda je v grafu smyčka
- Zda je graf hodnocený
- Zda je graf orientovaný
- Souvislost grafu
- Planaritu grafu
- Všechny tyto informace na konci vypíše metoda **analyse()**

### Technologie
Vše bylo napsáno v python OOP
